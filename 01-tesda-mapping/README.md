# TESDA Competency Mapping

This section maps practical Cisco CyberOps laboratory evidence to the core competencies of:

- **Cyber Threat Monitoring NC I**
- **Cyber Threat Mitigation NC II**

The mapping is evidence-oriented. A lab is not marked as demonstrating a competency merely because its topic sounds similar. The repository should contain observable evidence supporting the claimed element.

## Core Units

### Cyber Threat Monitoring NC I

- **ICT251312 — Monitor and report cyber threats**
- **ICT251313 — Conduct vulnerability scanning of assets**

### Cyber Threat Mitigation NC II

- **ICT251314 — Perform threat mitigation**
- **ICT251315 — Perform vulnerability management/control**

## Mapping Philosophy

Use three labels:

- **Direct** — the Cisco activity produces evidence closely matching the TESDA performance requirement.
- **Supporting** — the activity contributes knowledge/skills but does not by itself demonstrate the complete requirement.
- **Gap / Additional Exercise** — the Cisco activity does not sufficiently demonstrate the requirement and a supplementary lab should be performed.

This distinction is important because Cisco course completion and TESDA competency certification are not the same thing.
