# TESDA Core Competency Map

## ICT251312 — Monitor and Report Cyber Threats

| TESDA element | Portfolio evidence to collect | Suggested CyberOps evidence |
|---|---|---|
| 1. Check for alerts | alert screenshot, alert details, validation notes, ticket/case record | security alert / monitoring labs |
| 2. Check status of third-party security solution | security tool status, operational check, scan capability | endpoint/security solution labs |
| 3. Perform manual checking and verification | manual log review, endpoint check, scan result, verification notes | log, endpoint and investigation labs |
| 4. Conduct case follow-up | scan/action result, failed action, escalation record | investigation and reporting labs |
| 5. Perform alert reporting | incident report, severity, spread/lateral movement, ingress/egress analysis | reporting and incident labs |

TESDA's evidence guide for ICT251312 specifically calls for evidence covering alerts, security-solution status, manual verification, case follow-up and alert reporting.

## ICT251313 — Conduct Vulnerability Scanning of Assets

| TESDA element | Portfolio evidence to collect | Suggested evidence |
|---|---|---|
| 1. Check schedule for scanning | scope, asset list, authorization/schedule record | vulnerability-scanning activity |
| 2. Conduct scanning of assets | scan configuration, target scope, scan output | vulnerability scan |
| 3. Provide report of scanning | findings, severity, affected assets, recommendations | vulnerability report |

## ICT251314 — Perform Threat Mitigation

| TESDA element | Portfolio evidence to collect | Suggested evidence |
|---|---|---|
| 1. Check for incidents | alert validation, classification, priority, scope | incident investigation |
| 2. Use cyber threat intelligence | CTI sources, IOC validation, TTP mapping, applicability | threat intelligence |
| 3. Check running processes/configs | process listings, file/configuration checks, integrity evidence | endpoint analysis |
| 4. Implement containment and recovery | IOC blocking, isolation, monitoring, recovery/rollback, secondary scan, report | containment + recovery capstone |

## ICT251315 — Perform Vulnerability Management/Control

| Evidence area | Portfolio evidence |
|---|---|
| Asset identification | asset inventory |
| Vulnerability identification | scan results |
| Analysis | vulnerability interpretation and prioritization |
| Control/remediation | remediation plan |
| Validation | post-remediation scan or verification |
| Reporting | management/technical vulnerability report |

> The exact evidence claimed for ICT251315 should be checked against the current TESDA Training Regulations and the assessment requirements applicable to the intended assessment.
