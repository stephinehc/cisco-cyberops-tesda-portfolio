# CyberOps-to-TESDA Integrated Capstone

## Objective

Demonstrate an end-to-end cybersecurity workflow using evidence produced from the Cisco CyberOps laboratory environment.

The capstone should progress from detection through investigation, threat intelligence, mitigation, containment and recovery.

## Recommended Scenario

A monitored endpoint generates suspicious activity. The analyst must determine whether the activity represents a security incident, identify the affected asset and indicators, determine scope and severity, apply appropriate containment/mitigation actions, recover the system, validate the result and report the incident.

## TESDA Focus

### ICT251312

Show monitoring, verification, case follow-up and alert reporting.

### ICT251313

If vulnerability scanning is part of the scenario, document scope, scan execution and reporting.

### ICT251314

This is the primary capstone competency. Demonstrate incident checking, CTI use, process/configuration analysis, containment and recovery.

### ICT251315

Include vulnerability management evidence where applicable.

## Important

If the original Cisco laboratory only demonstrates detection/investigation, do not claim that it demonstrated containment or recovery. Use a controlled supplementary exercise for the missing evidence.
