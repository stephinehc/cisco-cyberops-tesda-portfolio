# Containment and Recovery Checklist

Use this checklist only for an authorized laboratory environment.

## Containment

- [ ] Confirm alert
- [ ] Identify affected asset
- [ ] Identify IOC(s)
- [ ] Identify relevant TTP(s)
- [ ] Determine scope
- [ ] Select containment strategy
- [ ] Block applicable IOC(s)
- [ ] Isolate affected endpoint/network segment where supported
- [ ] Preserve relevant evidence
- [ ] Monitor for repeated malicious activity
- [ ] Record all actions

## Recovery

- [ ] Identify last-known-good image/configuration/backup
- [ ] Confirm recovery point
- [ ] Perform rollback/restoration if appropriate
- [ ] Remove malicious artifacts where applicable
- [ ] Perform secondary scan
- [ ] Validate system functionality
- [ ] Monitor for recurrence
- [ ] Document recovery result

## Reporting

- [ ] Update incident timeline
- [ ] Record containment actions
- [ ] Record recovery actions
- [ ] Record remaining risk
- [ ] Notify simulated stakeholder where applicable
- [ ] Complete final incident report
- [ ] Record lessons learned

## Evidence

For every checked item, link to the corresponding evidence file.
