# Evidence Repository

Store original evidence here and reference it from the individual laboratory reports.

## Recommended Naming

```text
LAB001_01_initial_state.png
LAB001_02_alert.png
LAB001_03_log_analysis.png
LAB001_04_network_analysis.png
LAB001_05_result.png
CASE001_incident_report.pdf
CASE001_timeline.png
```

## Evidence Rules

Evidence should be:

- attributable to a specific laboratory/case
- dated where practical
- understandable without hidden context
- sanitized of credentials and sensitive information
- accompanied by an explanation of what it demonstrates

Do not store proprietary Cisco course answer keys or copied lab solutions.
