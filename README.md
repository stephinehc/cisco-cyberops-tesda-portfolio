# Cisco CyberOps Associate — TESDA Cybersecurity Competency Portfolio

A practical cybersecurity portfolio documenting laboratory work performed in the Cisco CyberOps Associate learning environment and mapping the resulting evidence to the **TESDA Cyber Threat Monitoring NC I** and **Cyber Threat Mitigation NC II** core competencies.

## Purpose

This repository is designed as a **skills-evidence portfolio** rather than a collection of lab answers. Each completed Cisco CyberOps laboratory should show:

**Activity → Evidence → Observation → Analysis → Finding → Action → Result → Report → TESDA competency alignment**

The portfolio is intended to demonstrate practical skills in:

- security monitoring and alert handling
- log and event analysis
- network traffic analysis
- endpoint investigation
- malware and indicator analysis
- vulnerability scanning
- incident investigation
- cyber threat intelligence
- threat mitigation
- containment
- recovery
- incident reporting and documentation

## TESDA Core Competencies

### Cyber Threat Monitoring NC I

| Unit | Core competency |
|---|---|
| ICT251312 | Monitor and report cyber threats |
| ICT251313 | Conduct vulnerability scanning of assets |

### Cyber Threat Mitigation NC II

| Unit | Core competency |
|---|---|
| ICT251314 | Perform threat mitigation |
| ICT251315 | Perform vulnerability management/control |

TESDA's 2024 Training Regulations describe NC I as covering monitoring/reporting cyber threats and vulnerability scanning, while NC II covers threat mitigation and vulnerability management/control.

## Evidence Principle

A screenshot alone is not considered sufficient evidence. For significant activities, document:

1. What was the objective?
2. What was observed?
3. What evidence was collected?
4. What does the evidence mean?
5. What decision was made?
6. What action was taken?
7. What was the result?
8. Which TESDA competency element does the evidence demonstrate?
