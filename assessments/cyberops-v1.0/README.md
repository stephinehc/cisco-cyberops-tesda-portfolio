# Cisco CyberOps Associate v1.0 Skills Assessment

## Assessment

**Scenario:** Pushdo Trojan investigation

**Environment:** Cisco CyberOps Associate VM / Security Onion

**Assessment type:** Alert-driven SOC investigation

## Purpose in this portfolio

This assessment is an integrated practical activity that brings together skills developed through the CyberOps Associate laboratory activities.

It is primarily used as high-value evidence for:

- **ICT251312 — Monitor and Report Cyber Threats**
- Supporting evidence for **ICT251314 — Perform Threat Mitigation**

It is not, by itself, evidence of:

- ICT251313 — Conduct Vulnerability Scanning of Assets
- ICT251315 — Perform Vulnerability Management/Control
- containment
- eradication
- recovery
- secondary scanning
