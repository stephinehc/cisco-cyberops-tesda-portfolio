# Capstone Scenario

A simulated organization detects suspicious outbound traffic from a Windows workstation. An IDS alert identifies unusual activity.

The analyst must determine whether the event is malicious, identify the affected host, analyze logs and network traffic, extract indicators, correlate them with threat intelligence, contain the incident, recover the endpoint, verify the clean state, and report the result.

## Required tasks

1. Validate alert.
2. Identify affected asset.
3. Analyze logs.
4. Analyze network traffic.
5. Identify IOCs.
6. Perform CTI enrichment.
7. Identify relevant TTPs.
8. Classify and prioritize incident.
9. Contain affected system.
10. Recover from known-good state.
11. Perform secondary scan.
12. Verify normal operation.
13. Produce final incident report.
