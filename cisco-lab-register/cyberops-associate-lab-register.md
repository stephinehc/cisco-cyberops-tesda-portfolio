# Cisco CyberOps Associate Lab Register

## Purpose

This is the master register for **Cisco CyberOps Associate laboratory activities**, maintained in the original Cisco sequence. It connects each lab to the portfolio's fixed 11 evidence domains and later to TESDA performance criteria.

## Fixed evidence domains

| ID | Evidence domain |
|---|---|
| 01 | Monitoring and Alerts |
| 02 | Log/Event Analysis |
| 03 | Network Traffic Analysis |
| 04 | Endpoint Analysis |
| 05 | Malware/IOC Analysis |
| 06 | Vulnerability Scanning |
| 07 | Incident Investigation |
| 08 | Threat Intelligence |
| 09 | Containment |
| 10 | Recovery |
| 11 | Reporting |

## Register principles

1. **Preserve Cisco sequence.** Labs remain in their original CyberOps Associate order.
2. **Assign one primary evidence domain.** This determines the main portfolio location.
3. **Allow related domains.** A lab may support multiple domains without duplicating its full evidence package.
4. **Map TESDA separately.** Evidence domains are portfolio categories, not TESDA competencies.
5. **Do not overclaim.** Coverage is rated Direct, Supporting, or Gap based on demonstrated performance.
6. **Use actual evidence only.** Screenshots, outputs, logs, PCAPs, reports and other artifacts must come from the performed lab.

## Register fields

| Field | Description |
|---|---|
| Lab No. | Cisco module/lab number |
| Lab Activity | Cisco lab title |
| Primary Domain | One of the 11 evidence domains |
| Related Domains | Other applicable evidence domains |
| CyberOps Skill | Main skill demonstrated |
| NC I | Relevance to CTM NC I |
| NC II | Relevance to CTM NC II |
| TESDA Competency | Applicable core competency |
| Coverage | Direct / Supporting / Gap |
| Evidence | Artifacts to capture |
| Portfolio Path | Expected evidence folder |
| Supplementary | Additional activity needed, if any |
