# Lab 04 — Using Windows PowerShell

**Cisco activity:** 3.3.11  
**Primary domain:** 04 Endpoint Analysis  
**Environment:** Simulated, isolated, controlled laboratory only.

## Tasks, Answers and Observations

### Task 1 — Compare command interfaces
Run `dir`, `ping`, `cd`, and `ipconfig` from Command Prompt and PowerShell.

**Observation:** Both environments can execute common commands and produce comparable basic results. PowerShell also exposes object-oriented cmdlets and richer formatting/properties.

### Task 2 — Explore cmdlets
Use PowerShell commands to inspect the system and networking information.

**Answer / observation:** PowerShell supports administrative and investigation tasks through cmdlets and pipeline operations.

### Task 3 — Examine `netstat`
**Observation:** `netstat` can display active connections, listening ports and associated network information.

### Task 4 — Empty the Recycle Bin
The PowerShell procedure clears the simulated user's Recycle Bin as instructed.
