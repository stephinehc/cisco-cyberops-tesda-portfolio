# Lab 05 — Windows Task Manager

**Cisco activity:** 3.3.12  
**Primary domain:** 04 Endpoint Analysis  
**Environment:** Simulated, isolated, controlled laboratory only.

## Tasks, Answers and Observations

### Task 1 — Processes tab
Open Task Manager and expand the Windows Command Processor entry.

**Answer:** `Command Prompt` is listed under the Windows Command Processor grouping.

### Task 2 — Process categories
**Observation:** Task Manager separates processes into Apps, Background processes, and Windows processes.

### Task 3 — Services and performance
Inspect the Services and Performance tabs and identify active services and resource utilization.

**Observation:** Task Manager provides service status and CPU, memory, disk, network and other performance information.

### Task 4 — Process management
Use the assigned laboratory process-management action and observe the resulting state.
