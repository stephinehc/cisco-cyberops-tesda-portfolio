# Lab 06 — Monitor and Manage System Resources in Windows

**Cisco activity:** 3.3.13  
**Primary domain:** 04 Endpoint Analysis  
**Environment:** Simulated, isolated, controlled laboratory only.

## Tasks, Answers and Observations

### Task 1 — Service management
Use the assigned Windows service in the laboratory and observe its state before and after the instructed action.

**Observation:** The service state changes according to the action performed and can be verified through the Windows management interface.

### Task 2 — Computer Management
**Observation:** Computer Management provides administrative views for services, events, users/groups, storage and other system resources.

### Task 3 — Administrative tools
**Answer:** Windows Administrative Tools provide utilities for monitoring and managing system resources and services.
