# Lab 07 — Working with Text Files in the CLI

**Cisco activity:** 4.2.6  
**Primary domain:** 02 Log/Event Analysis  
**Environment:** Simulated, isolated, controlled laboratory only.

## Tasks, Answers and Observations

1. Open a text editor from the GUI and terminal.
2. Locate configuration files and inspect their contents.
3. Edit and save the assigned configuration file.
4. Verify the resulting file contents.

**Answer / observation:** Text and configuration files can be located, viewed and edited from the Linux command line. Configuration changes should be verified after saving.
