# Lab 08 — Getting Familiar with the Linux Shell

**Cisco activity:** 4.2.7  
**Primary domain:** 04 Endpoint Analysis  
**Environment:** Simulated, isolated, controlled laboratory only.

## Tasks, Answers and Observations

1. Access the Linux command line.
2. Use manual pages and basic shell commands.
3. Create/change directories.
4. Redirect command output and append to files.
5. Work with hidden files.
6. Copy, delete and move files/directories.

**Answer / observation:** The Linux shell supports filesystem navigation, file manipulation, output redirection and administrative operations through command-line tools.
