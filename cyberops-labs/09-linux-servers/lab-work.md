# Lab 09 — Linux Servers

**Cisco activity:** 4.3.4  
**Primary domain:** 04 Endpoint Analysis  
**Environment:** Simulated, isolated, controlled laboratory only.

## Tasks, Answers and Observations

1. Access the Linux command line.
2. Display services currently running.
3. Identify server services and listening ports.
4. Use Telnet only against the designated laboratory service to test TCP connectivity.

**Answer / observation:** Linux service/process tools identify active services and their listening ports. Telnet can confirm whether a designated TCP service accepts a connection in the lab.
