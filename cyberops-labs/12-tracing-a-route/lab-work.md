# Lab 12 — Tracing a Route

**Cisco activity:** 5.1.5  
**Primary domain:** 03 Network Traffic Analysis  
**Environment:** Simulated, isolated, controlled laboratory only.

## Tasks, Answers and Observations

1. Verify connectivity with ping.
2. Trace the route to the assigned remote destination.
3. Compare the local traceroute result with the assigned web-based trace when required.
4. Interpret intermediate hops and latency.

**Answer / observation:** Ping verifies reachability. Traceroute reveals the sequence of network hops between the source and destination; exact hops vary with the test environment.
