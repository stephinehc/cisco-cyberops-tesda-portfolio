# CyberOps Associate v1.0 — Individual Lab Evidence

This directory contains the individual practical-work records for the **36 CyberOps Associate v1.0 laboratory activities selected in the master lab register**.

## Purpose

Each lab folder contains the candidate's practical work record: tasks/questions, expected/reference answers, observations, interpretation, and standardized locations for the candidate's own screenshots.

## Folder structure

```text
cyberops-labs/
├── 01-identify-running-processes/
├── 02-processes-threads-handles-registry/
├── ...
└── 36-investigating-windows-host-attack/
```

Each folder uses:

```text
lab-work.md
screenshots/
```

The `screenshots/` directory will contain only candidate-generated evidence from the authorized laboratory run. It will be populated manually later.

## Evidence naming standard

```text
LAB-XX-01-short-description.png
LAB-XX-02-short-description.png
LAB-XX-03-short-description.png
```

`XX` is the portfolio lab number, not the Cisco module number.

## Evidence rule

The answers and observations in the Markdown records are reference guidance used to structure the documentation. They are not proof that the candidate performed the activity.

The final evidence chain must be:

```text
Lab task
   ↓
Candidate performs activity
   ↓
Actual result / observation
   ↓
Candidate screenshot or command output
   ↓
Interpretation
   ↓
Evidence domain
   ↓
TESDA criterion
```

## Environment and privacy

All activities must be performed only in a **simulated, isolated, and controlled laboratory environment** using authorized training virtual machines, simulated networks, packet captures, training datasets and intentionally configured systems.

Do not use production systems, live organizational networks, third-party systems, confidential company information, personally identifiable information, production credentials or private keys.

## Relationship to the 11 evidence domains

The individual lab folders are the source of the candidate's practical work. The 11 evidence-domain folders classify and index what the work demonstrates; they should not contain unnecessary duplicate copies of the complete lab reports.
