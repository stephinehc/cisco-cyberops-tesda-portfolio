# Evidence Repository

Store actual evidence generated by completed labs.

## Directories

```text
screenshots/
packet-captures/
logs/
command-output/
malware-analysis/
reports/
```

## Naming convention

`<lab-or-supplement>_<description>_<evidence-type>_<sequence>`

Example:

`27.2.16_windows-host_process-list_screenshot_01.png`

## Rules

- Keep raw evidence unchanged where possible.
- Explain derived/processed evidence.
- Remove secrets and personal information.
- Do not upload live malicious payloads.
- Prefer sanitized hashes/indicators when appropriate.
