# Supplementary Laboratory Program

These six controlled exercises close evidence gaps between Cisco CyberOps activities and the TESDA performance criteria.

| ID | Lab | Main TESDA unit |
|---|---|---|
| SUP-01 | SOC Alert & Case Management | ICT251312 |
| SUP-02 | Security Solution Health & Verification | ICT251312 |
| SUP-03 | CTI / IOC Enrichment | ICT251314 |
| SUP-04 | Containment & Recovery | ICT251314 |
| SUP-05 | Vulnerability Scanning Operations | ICT251313 |
| SUP-06 | Vulnerability Management Lifecycle | ICT251315 |

All exercises should be performed only in an isolated, authorized laboratory environment.
