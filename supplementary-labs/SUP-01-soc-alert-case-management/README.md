# SUP-01 — SOC Alert & Case Management

## Purpose

Demonstrate alert intake, SOP validation, classification, ticketing, escalation and stakeholder reporting.

## Workflow

Alert → SOP validation → Red-flag check → Assessment → Classification → Ticket → Escalation → Notification → Report

## Required evidence

- simulated SOP
- alert screenshot
- validation worksheet
- severity decision
- ticket
- escalation record
- stakeholder notification
- final alert report

## TESDA

Primary: ICT251312 Elements 1, 4 and 5.
