# SUP-02 — Security Solution Health & Verification

## Purpose

Demonstrate security-solution installation/status, operational verification, update status and controlled remediation testing.

## Workflow

Installed? → Operational? → Updated? → Test detection → Remediation action → Verification

## Evidence

- product/version
- service/status evidence
- update status
- controlled benign test
- quarantine/remediation result
- verification
- report

Do not use live malware.
