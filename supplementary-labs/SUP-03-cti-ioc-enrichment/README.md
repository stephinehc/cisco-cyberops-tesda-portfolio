# SUP-03 — CTI / IOC Enrichment

## Purpose

Demonstrate IOC counter-checking, infrastructure applicability, TTP identification, ATT&CK mapping, control selection and knowledge-base updating.

## Workflow

IOC → Source 1 → Source 2 → Confidence → Infrastructure applicability → TTP → ATT&CK → Control → Monitoring → Knowledge base

## Evidence

- IOC
- two-source validation
- confidence assessment
- applicability worksheet
- TTP/ATT&CK mapping
- control/blocking evidence
- monitoring result
- CTI report
- knowledge-base entry
