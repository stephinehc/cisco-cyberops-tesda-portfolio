# SUP-04 — Containment & Recovery

## Purpose

Demonstrate complete containment and recovery in a disposable lab environment.

## Workflow

Detect → Identify IOC → Block → Isolate → Monitor → Preserve evidence → Last-known-good → Rollback → Remove artifact → Validate → Secondary scan → Report

## Evidence

- initial alert
- IOC table
- firewall/control rule
- isolation evidence
- monitoring evidence
- snapshot/backup selection
- rollback evidence
- artifact removal
- service validation
- secondary scan
- final recovery report

Use only disposable lab systems.
