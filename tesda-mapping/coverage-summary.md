# TESDA Coverage Summary — Phase 1

## Overall evidence picture

| TESDA core competency | Best evidence source | Current portfolio position |
|---|---|---|
| **ICT251312 — Monitor and report cyber threats** | CyberOps v1.0 + v1.1 + BOTS v2 | 🟢 Strong |
| **ICT251313 — Conduct vulnerability scanning of assets** | CyberOps Nmap + supplementary VM workflow | 🟡 Partial |
| **ICT251314 — Perform threat mitigation** | CyberOps v1.1 + BOTS v2 + containment/recovery lab | 🟡 Strong investigation; mitigation gap remains |
| **ICT251315 — Perform vulnerability management/control** | Nmap + dedicated VM/remediation lab | 🔴 Gap until supplementary lab is completed |

## Recommended portfolio architecture

### NC I

**Primary practical:** CyberOps v1.0 Skills Assessment

**Supporting:** CyberOps monitoring/log/PCAP labs and BOTS v2

**Vulnerability component:** Nmap + TESDA-style scan planning, analysis, reporting and secondary scan

### NC II

**Advanced investigation:** CyberOps v1.1 + BOTS v2

**Mitigation completion:** dedicated containment/eradication/recovery simulation

**Vulnerability management completion:** dedicated vulnerability-management/remediation workflow

## Phase 1 conclusion

The portfolio should present CyberOps and BOTS v2 as **evidence sources within a broader competency architecture**, not as substitutes for the TESDA competency standards. The remaining gaps will be addressed in the supplementary-lab phase.

## Next phase

Phase 2 should build the **complete Cisco CyberOps Associate lab register in original Cisco sequence**, with each lab assigned to one or more of the 11 evidence domains and tagged as NC I, NC II, both, supporting, or gap.
