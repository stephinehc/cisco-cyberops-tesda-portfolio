# Final Gap Analysis

## Gap 1 — SOC alert/case management
Cisco provides strong detection and investigation, but the portfolio must add SOP intake, ticketing, severity, escalation and stakeholder notification.

**Supplement:** SUP-01.

## Gap 2 — Security solution health/remediation
Cisco demonstrates Snort/firewall concepts but not the complete third-party security-product lifecycle.

**Supplement:** SUP-02.

## Gap 3 — Threat intelligence
Cisco provides IOC/hash/network-analysis evidence, but TESDA expects counter-checking, applicability, TTP identification, blocking, continuous monitoring and knowledge-base updating.

**Supplement:** SUP-03.

## Gap 4 — Containment/recovery
Cisco strongly supports investigation and some containment concepts, but complete last-known-good recovery, rollback, secondary verification and reporting require dedicated evidence.

**Supplement:** SUP-04.

## Gap 5 — Vulnerability scanning operations
Nmap provides strong technical scanning evidence but does not by itself demonstrate authorization, scheduling, resource monitoring, scan interruption and formal reporting.

**Supplement:** SUP-05.

## Gap 6 — Vulnerability management/control
ICT251315 extends beyond scanning into asset control, scheduling, ITIL/change management, CAB, remediation and patch testing.

**Supplement:** SUP-06.
